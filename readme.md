AdotaPatas

Portal de Adoção e Gestão Animal

Sobre o projeto

O AdotaPatas é uma aplicação desenvolvida em C# .NET para facilitar a gestão de um abrigo de animais e o processo de adoção.

A aplicação centraliza a informação sobre animais, candidatos e candidaturas, permitindo uma gestão mais organizada e eficiente.

Problema

Muitos abrigos utilizam redes sociais e outros meios pouco organizados para divulgar animais e gerir candidaturas. Isto pode causar perda de informação, dificuldade no acompanhamento dos processos e maior carga de trabalho administrativo.

O AdotaPatas pretende resolver este problema através de uma plataforma centralizada.

Objetivos

* Gerir os animais do abrigo;
* Gerir os dados dos candidatos;
* Permitir pesquisar e filtrar animais;
* Registar e acompanhar candidaturas de adoção;
* Atualizar o estado das candidaturas;
* Centralizar a informação numa base de dados.

Tecnologias

O projeto utiliza:

* C# .NET / Windows Forms — desenvolvimento da aplicação;
* SQL Server — armazenamento dos dados;
* Git e GitHub — controlo de versões e trabalho em equipa;
* Visual Studio — ambiente de desenvolvimento.

Funcionalidades principais

A aplicação permitirá gerir os registos dos animais, incluindo informações como nome, espécie, idade, porte, género, descrição, fotografia e estado.

Também permitirá gerir os candidatos e acompanhar as candidaturas, que poderão apresentar diferentes estados, como Pendente, Em Análise, Aprovada ou Rejeitada.
